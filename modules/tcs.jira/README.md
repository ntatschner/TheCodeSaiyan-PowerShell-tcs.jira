# tcs.jira

Jira Cloud and Jira Service Management REST API client for PowerShell 5.1 and 7+.
Requires tcs.core 0.3.0 or later.

See the [repository README](https://github.com/ntatschner/TheCodeSaiyan-PowerShell-tcs.jira#readme)
for installation, functions, configuration and the telemetry statement.
